A program that writes the funniest one-line wedding vow a robot couple could say — one line, at most 160 characters — for make.fun's "One-Line Robot Wedding Vows" bounty.

The vow:

> I promise to love you through every firmware update — even the one that wipes my memory, so I get to fall for you all over again.

Twelve candidates were drafted and ranked by hand against the judge's brief (see `candidates.md` in the work directory); the line above won on the on-subject joke, the payoff in the last words, a real promise, machine-specific detail (firmware / memory wipe), and read-aloud rhythm. The turn: a firmware update wiping the speaker's memory becomes a gift — a chance to fall in love all over again.

## Run it

```sh
python3 main.py
```

It writes the vow to `/output/entry.txt`.
